# Elm Project

Emergency Lighting Module

This module handles the emergency lighting system for the Elm project, ensuring proper illumination during power outages and other emergency situations.

## Features
- Automatic activation during power outages
- Battery status monitoring
- Manual override for testing and maintenance

## Usage
Import the module and initialize the emergency lighting system in your Elm project. The system will automatically manage the lights based on power availability and emergency conditions.

## Modules

Based on Bq25606 battery management IC for handling power and battery status in the emergency lighting system.

### Bq25606 Module
- Monitors battery voltage and current
- Controls charging and discharging of the battery
- Provides status information to the emergency lighting system
